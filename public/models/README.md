# Bugatti 3D Models Directory

Place any `.glb` or `.gltf` 3D car models here (e.g., `tourbillon.glb`, `bolide.glb`, `chiron.glb`).

The application features:
- Live procedural Bugatti hypercar 3D mesh (chassis, C-line, horseshoe grille, active rear aero wing, multi-piece wheels, brake calipers, LED optics) rendered with Three.js & `@react-three/fiber`
- Automatic loading for custom GLTF/GLB models if specified in `SupercarModel.tsx` or configurator presets.
